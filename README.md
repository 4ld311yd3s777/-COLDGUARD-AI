# COLDGUARD AI

Mô hình dự báo và quản trị rủi ro chuỗi lạnh đối với hàng hóa xuất khẩu.

## Giới thiệu
COLDGUARD AI là mô hình prototype mô phỏng việc dự báo rủi ro chuỗi lạnh cho các container nông sản (ví dụ: xoài xuất khẩu) đang chờ thông quan. Hệ thống kết hợp dữ liệu nhiệt độ, độ ẩm, thời gian chờ, thời gian vận chuyển và tình trạng nguồn điện để tính toán **Cold Chain Risk Score** và đưa ra đề xuất hành động.

## Cài đặt & Chạy ứng dụng

```bash
pip install -r requirements.txt
streamlit run app.py
```
